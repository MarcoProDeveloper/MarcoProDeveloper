##  Sobre mim

Sou **desenvolvedor Fullstack** com cerca de **2 anos de experiência** em desenvolvimento web. Meu foco é resolver problemas técnicos de forma prática: entender o que o negócio precisa, escolher a solução mais simples que funciona e entregar.

-  Atuo como **desenvolvedor no Cruzeiro Esporte Clube SAF**, trabalhando em Frontend e Backend, incluindo **páginas com funcionamento embarcado dentro do Salesforce**.
-  Construo **automações e integrações** com n8n, APIs REST e serviços de calendário (Microsoft Graph e Google Calendar).
-  Desenvolvo **sites e landing pages** como freelancer, com contrato formal, checklist de entrega e atenção à LGPD.
-  Uso **IA como ferramenta de produtividade** no dia a dia, sempre revisando, testando e entendendo o código que vai para produção.

>  **Aberto a novas oportunidades** como desenvolvedor Fullstack / Web. Vamos conversar?
